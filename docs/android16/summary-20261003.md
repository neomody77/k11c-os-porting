# K11C Android16 阶段总结

截至 2026-10-03（Asia/Singapore），Android16 已写入 K11C eMMC，原生首启和一次正常重启均完成，API36.1、SELinux Enforcing、USB ADB 与 Wi-Fi 默认网络正常。当前不依赖 DSU 启动。用户要求本阶段到此结束，后续兼容性测试和开发暂停。

这是自编译 AOSP ARM64 GSI 搭配原厂 kernel/vendor 的实验系统；不是完整 Rockchip Android16 BSP，也未通过完整 CTS/VTS。原始日志、设备标识、闭源库、镜像和加密数据备份均保留在私有空间。

刷写前停止界面服务、冻结 /data 与 /metadata，保存27,012,857,856字节 userdata及16,777,216字节 metadata，并与冻结状态下的板端完整哈希核对。原厂 super及当前boot等恢复镜像也已保存。保留备份不等于已经完成本次原生安装后的Android13回退测试；Android16可能升级数据，回退时须评估配套恢复userdata/metadata。

镜像哈希、分区布局和准备工具见 [原生安装记录](native-install-20261002.md)。super内部只替换system，其他七个逻辑分区保留原厂内容；原生boot移除旧system_ext/product挂载，使GSI内嵌内容生效。第十补丁将兼容修复的开关改为镜像只读属性，支持原生启动。

第二次正常启动完成后静置30秒，保持亮屏、未主动运行压力任务，采集7个快照，间隔约10秒，总窗口63.15秒。CPU由/proc/stat差值计算，排除idle与iowait，四核总容量归一化为100%；仍包含ADB与采样开销。

| I/O等待 | 分段0–0.02% |
| 内核可见RAM | 3,993,136KiB，约3.81GiB |

MemAvailable、Android内存账本与RSS使用不同口径，不能相加。进程VIRT是地址空间，不是实体RAM占用。

| --- | ---: | --- |
| system_server | 约382–385MiB | 无 |
| SurfaceFlinger | 约77.16MiB | 无 |

| 原生RTC服务 | 约2.93MiB | 无 |

RSS包含共享页，表中各项不能求和代表整体内存。近期日志未观察到FATAL EXCEPTION或Fatal signal标记；这只是短时观察，不是长时稳定性验证。

18.30GiB已用空间主要含历史实验数据：已停用的DSU目录约9.78GiB，/data/local中的先前保留测试备份约8.13GiB。不能把这些文件算成Android16自身占用。本轮全部保留，没有为降低数字删除旧数据。

可复核的聚合结果见 [native-results-20261003.json](native-results-20261003.json)。本轮未重新做原生压力、视频或连续动画跑分；62Hz是显示配置观察，不等价于本轮实测62FPS。

## CTS/VTS及遗留事项

Sensors1.0 VTS在DSU阶段完整一轮36通过、0失败、1/1模块完成；空HAL通过接口测试不证明存在物理传感器。官方CTS16.1 R4 ARM已下载展开，同源完整VTS套件已构建。完整套件没有在当前原生安装上运行，不能声明通过CTS/VTS。此前不完整或受主机中断的结果没有计为板子通过。

剩余项目为物理传感器与匹配驱动、kernel GPU-work统计、Mac C→C角色检测、原生硬断电冷启动、升级数据后的13回退、RTC真实关机/唤醒、长时稳定性和完整CTS/VTS。摄像头、以太网、SD、USB-host外设、实际音质和电功耗没有完整验收。无SIM卡槽，实体modem/SIM/蜂窝按用户要求排除。userdebug su与未运行的厂商RTC类型仍声明permissive；全局Enforcing不等于生产安全认证。

本轮结束时没有运行中的编译、压力或CTS/VTS任务。临时nsjail AppArmor例外已卸载删除，CTS/VTS临时ADB转发已关闭，板端临时重启工具已移除，设备USB ADB及构建工作空间保留。Android17尚未选定源码或开始构建。
