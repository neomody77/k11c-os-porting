# Android17：板级集成与首次编译

截至2026-10-03，AVC回归模块编译成功，K11C板级集成镜像正在编译。尚无Android17镜像离线验收、设备启动或CTS/VTS通过结论。Android16原生系统和私有恢复材料保留，本轮没有向板子写入镜像。

## 固定输入与已完成验证

源码为`android-17.0.0_r1`，目标`aosp_arm64-cp2a-userdebug`，SDK37；逐项目引用固定清单和构建环境见[准备记录](preparation-20261003.md)。独立输出为`out/target/product/generic_arm64`，不覆盖Android16输出。

AVC溢出修正和4个新增用例已按17的测试文件重新定位。`CodecCapabilitiesTest`编译成功，用时565.05秒；这个结果只验证编译，运行和32/64位用例结果仍待Android17设备环境。

五个补丁均通过实际源码应用检查，首次和重复应用成功；新工具拒绝覆盖不一致的板级源码、拒绝非指定标签HEAD，并排除overlay里的private目录。25项已有工具测试通过；真实Android16私有RIL候选和被修改的17候选均被17打包入口拒绝，没有创建输出。

## 首次构建遇到的内存问题

构建虚拟机24vCPU、约40GiB RAM、32GiB swap，保留完整物理核心及SMT配对绑定；`-j12`控制编译任务数量，不能直接限制Soong全量依赖图内存。第一次图生成约31GiB RSS、26GiB swap并频繁内存等待，因此主动取消；保留日志，不记作源码编译失败。

普通export不生效的原因是Blueprint通过`env -i`启动生成器。补丁仅转发显式设置的Go运行时参数，实际子进程环境已确认`GOMEMLIMIT=24GiB`、`GOGC=50`。它是软内存预算，不保证硬上限，GC可能增加CPU成本；采用此配置后AVC依赖图和模块编译通过。系统镜像运行时不包含这些参数。

Linux构建沙箱需要临时精确路径nsjail AppArmor user namespace例外。专用私有构建入口持锁、核对程序哈希、仅在构建期间加载例外，成功、失败及主动取消均卸载并删除；AVC阶段清理已核对，完整镜像编译期间例外处于加载状态。没有修改全局user namespace设置。

## Android17专用RIL候选

仅将helper的SDK36/release16改为SDK37/release17是不够的：Android16厂商候选内部只接受release160。首次集成生成已暂停，重新从精确原库生成只接受release170、使用原RIL协议12函数表的候选，保留原系统属性和未知版本拒绝行为。相对16候选只改变一个比较字节，独立参考候选逐字节相同。

| 项目 | SHA256 |
|---|---|
| 精确原库 | 242fe86dfbdb5796674077ac55ffa4f6facc067c4b3e1bf519f0da5d2925ab5b |
| Android17候选 | 9f82653c2da377bd96416cee9f32a9574cb5e73a1249e4f37b606c123fa70010 |

原库与候选均为769528字节。helper从原库转换并检查完整输出哈希，同时与镜像中只读载荷逐字节比较；SDK37/release17、vendor API33、板型和userdebug条件全部匹配才发布给init。init负责只读bind，helper没有挂载权限。原厂vendor库不改写。

候选尚未在Android17上运行。版本分支放行是静态移植，不能宣称厂商HAL对新framework已兼容。没有SIM卡槽，实体modem/SIM功能继续按用户要求排除。厂商二进制只保存在私有工作区，公开仓库和Git历史不包含它。

## 复现入口

先按[准备文档](preparation-20261003.md)准备独立固定标签源码与构建沙箱，再执行：

```bash
bash tools/apply-android17.sh /path/to/aosp17
python3 tools/prepare-vendor-ril-android17.py \
  --factory-library /path/to/private/factory-librk-ril.so \
  --out /path/to/private/android17-ril-candidate
AOSP_ROOT=/path/to/aosp17 JOBS=12 \
  K11C_RIL_LIBRARY=/path/to/private/android17-ril-candidate/librk-ril.so \
  bash tools/build-android17.sh
```

构建入口默认设置24GiB软内存预算与GOGC50，可通过`K11C_SOONG_MEMORY_LIMIT`和`K11C_SOONG_GC_PERCENT`调整。它编译系统镜像、AVC与GPU-work测试模块，并检查实际ext4镜像中helper、RTC、RIL和空传感器HAL的SELinux标签。构建入口不自行扩大主机权限；当前实验由外部专用入口管理临时沙箱例外。

完成编译后还需以实际kernel配置和vendor VINTF进行静态兼容检查、ext4与AVB完整性检查、镜像容量和恢复方案确认。runtime APEX及旧HAL调用关系需要设备验证。任何编译成功或静态检查通过都不等同于板上启动成功。
